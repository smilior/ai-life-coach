## 1. 画面一覧とサイトマップ

### 1.1 画面階層構造

```
/                           # ランディング/スプラッシュ
├── /auth
│   ├── /login              # ログイン画面
│   └── /callback           # OAuth コールバック
│
├── /onboarding             # オンボーディングフロー
│   ├── /welcome            # ウェルカム画面
│   ├── /purpose            # 目的設定
│   ├── /values             # 価値観インタビュー
│   ├── /motivation         # 動機特定
│   └── /complete           # 完了画面
│
├── /app                    # メインアプリ（認証必須）
│   ├── /dashboard          # ホーム/ダッシュボード
│   │
│   ├── /coaching           # コーチングセクション
│   │   ├── /chat           # AIチャット画面
│   │   ├── /sessions       # セッション履歴
│   │   └── /[sessionId]    # 個別セッション詳細
│   │
│   ├── /habits             # 習慣管理セクション
│   │   ├── /                # 習慣一覧
│   │   ├── /new            # 新規習慣作成
│   │   ├── /[habitId]      # 習慣詳細
│   │   └── /[habitId]/edit # 習慣編集
│   │
│   ├── /progress           # 進捗・統計セクション
│   │   ├── /               # 統計ダッシュボード
│   │   ├── /calendar       # カレンダービュー
│   │   └── /badges         # バッジ一覧
│   │
│   ├── /settings           # 設定
│   │   ├── /               # 設定メニュー
│   │   ├── /notifications  # 通知設定
│   │   ├── /theme          # テーマ設定
│   │   └── /account        # アカウント設定
│   │
│   └── /profile            # プロフィール
│       ├── /               # プロフィール表示
│       └── /edit           # プロフィール編集
│
└── /error                  # エラー画面
    ├── /404                # Not Found
    └── /500                # Server Error
```

### 1.2 画面一覧テーブル

| カテゴリ | 画面名 | URL | 認証 | 優先度 |
|---------|--------|-----|------|--------|

| オンボーディング | 完了 | `/onboarding/complete` | 必要 | P0 |
| メイン | ダッシュボード | `/app/dashboard` | 必要 | P0 |

## 2. 各画面の詳細設計

### 2.1 スプラッシュ/ランディング画面

**画面名**: スプラッシュ/ランディング
**URL**: `/`
**目的**: アプリの第一印象を与え、ログインまたはサインアップへ誘導

#### レイアウト
```
┌─────────────────────────────┐
│         StatusBar           │
├─────────────────────────────┤
│                             │
│                             │
│      ┌───────────────┐      │
│      │               │      │
│      │     Logo      │      │
│      │   Animation   │      │
│      │               │      │
│      └───────────────┘      │
│                             │
│     「AI Life Coach」       │
│                             │
│   ～ あなたの可能性を ～      │
│   ～ 解き放つパートナー ～    │
│                             │
│                             │
│  ┌─────────────────────┐    │
│  │    はじめる          │    │
│  │  (Primary Button)   │    │
│  └─────────────────────┘    │
│                             │
│     すでにアカウントを       │
│     お持ちの方はログイン     │
│                             │
├─────────────────────────────┤
│   SafeArea (Bottom)         │
└─────────────────────────────┘
```

#### UIコンポーネント
| コンポーネント | shadcn/ui | 説明 |
|---------------|-----------|------|
| ロゴ | カスタム | アニメーション付きSVG |
| メインボタン | `Button` variant="default" size="lg" | 新規登録フロー開始 |
| サブリンク | `Button` variant="link" | ログイン画面へ |

#### ユーザーインタラクション
- 「はじめる」タップ → `/auth/login` へ遷移（新規登録モード）
- 「ログイン」タップ → `/auth/login` へ遷移（ログインモード）
- 3秒後に自動フェードイン完了

#### 状態
- `isLoading`: 初期ロード中（スプラッシュアニメーション）
- `isAuthenticated`: 認証済みなら `/app/dashboard` へリダイレクト

#### UIコンポーネント
| コンポーネント | shadcn/ui | 説明 |
|---------------|-----------|------|
| ヘッダー | カスタム | 戻るボタン付き |
| Googleボタン | `Button` variant="outline" size="lg" | Google OAuth |

- `isLoading`: OAuth処理中
- `error`: 認証エラー（Toast表示）

```typescript
// 許可された場合
if (permission === 'granted') {
  showToast('通知を有効にしました 🔔');
  navigateToDashboard();
}

// 拒否された場合
if (permission === 'denied') {
  showToast('通知は設定から有効にできます');
  navigateToDashboard();
}
```
